# التشغيل للتطوير

## المتطلبات

- Node.js ‏22 فأحدث
- Docker (لقاعدة البيانات والطوابير)
- `ffmpeg` — مطلوب
- `yt-dlp` — لجلب الروابط فقط (اختياري)

## الإقلاع

```bash
npm install
cp .env.example .env      # ثم املأ مفاتيح المزوّدين
docker compose up -d      # Postgres + Redis
npm run db:push           # إنشاء الجداول
npm run dev               # http://localhost:3000
npm run worker            # في طرفية أخرى — بدونه لا يُفرَّغ شيء
```

**العامل عملية منفصلة عن خادم الويب.** مهمة التفريغ تستغرق دقائق، وطلب
HTTP لا ينتظرها. إن رفعت مقطعًا وبقي «في الانتظار»، فالعامل غير مشغَّل.

## المفاتيح المجانية

| المزوّد | الرابط | الدور |
|---|---|---|
| Groq | <https://console.groq.com/keys> | التفريغ الأساسي (`whisper-large-v3`) |
| Gemini | <https://aistudio.google.com/apikey> | التفريغ الثاني + المراجعتان |

كلاهما بطبقة مجانية بلا بطاقة. راجع حدود الحصص وتحذير الخصوصية في
[`PLAN.md` § 3](PLAN.md#3-اختيار-النماذج--مجانية-بالكامل) قبل رفع مادة حساسة.

بدون المفاتيح تعمل الواجهة والرفع؛ مراحل التفريغ والمراجعة تحتاجها.
وبديلهما وضع «مشروع خاص»: تفريغ ومراجعة محليّان بلا مفاتيح ولا إنترنت.

## الحالة الحالية

**م0 مكتملة:** الهيكل، قاعدة البيانات، الواجهة العربية RTL، المجلدات،
الرفع، لوحة المهام.

**م1 مكتملة:** `ffmpeg` والتطبيع، التقطيع عند الصمت بتداخل، مزوّدا Groq
وGemini، متتبّع الحصص ولوحتها، الدمج بالتداخل، مخطط الاختلاف، والعامل.

**م2 مكتملة (الأداة):** `npm run eval` يقيس WER بعد كل مرحلة ويخرج برمز
فشل إن رفعت مرحلةٌ الخطأ. **المجموعة نفسها ناقصة** — فيها مقطع اصطناعي
واحد، وتحتاج مقاطعك أنت مفرّغةً يدويًا ([`eval/README.md`](../eval/README.md)).
قياس المقاطع الصوتية (الخط الكامل) لم يُفعَّل بعد؛ النصّية تعمل.

**م3 مكتملة:** المرحلتان الثانية والثالثة، والحارس الذي يرفض كل تعديل
غير مبرّر. المراجعة تعمل الآن بعد التفريغ تلقائيًا.

**م4 مكتملة:** صفحة المقطع بمحرّر الاعتماد ومقارنة المراحل وجدول
التعديلات وأسبابها، والتصدير بخمس صيغ، وحذف الوسائط بعد الاعتماد
وكنّاس دوري للمقاطع المهجورة.

**م5 مكتملة:** استئناف التفريغ بعد نفاد الحصة، والرفع المجزّأ المستأنف
حتى 2 غيغابايت، والتحديد المتعدد مع التصدير الجماعي المضغوط والحذف
الجماعي.

الجدولة الليلية للدفعات **لم تُبنَ منفصلة عمدًا**: تأجيل المهام عند نفاد
الحصة يوزّع الدفعة الكبيرة على الأيام من تلقاء نفسه، فمُجدوِلٌ مستقل
يكرّر المنطق نفسه بلا فائدة.

**م6 مكتملة:** تسجيل الدخول وحماية كل صفحة ومسار، وجلب يوتيوب بـ
`yt-dlp`، وصفحة إعدادات المجلد والمسرد، والمسار المحلي (faster-whisper
+ Ollama) فيعمل وضع «مشروع خاص» فعليًا، وسكربت النسخ الاحتياطي.

**المشروع مكتمل بمراحله السبع.** ما بقي تجريب حقيقي: لم يُشغَّل أيٌّ من
هذا على مفاتيح ونماذج وملفات صوت فعلية.

## قبل الرفع على إنترنت عام

الخطوات كاملة في [`DEPLOY.md`](DEPLOY.md). وباختصار:

1. **`AUTH_SECRET`** — ولّده بـ `openssl rand -base64 32`. الموقع لا يقلع بدونه.
2. **HTTPS** — كوكي الجلسة يُرسَل `secure` في الإنتاج، فلا يعمل الدخول على
   HTTP. ضع Caddy أو أي وكيل عكسي بشهادة تلقائية.
3. **أول حساب** — افتح `/setup` وأنشئه فورًا. الباب يُغلق بعده تلقائيًا،
   لكنه مفتوح لأي زائر قبل ذلك.
4. **النسخ الاحتياطي** — `./scripts/backup.sh` في cron يوميًا، ثم انسخ
   المجلد إلى **جهاز آخر**. نسخة على القرص نفسه ليست نسخة احتياطية.
5. **الترحيلات** — `npm run db:push` (أو `db:migrate`) بعد كل تحديث.

## ما لم يُبنَ بعد

- **مشغّل صوت متزامن مع النصّ** — التوقيتات محفوظة والميزة شبه مجانية،
  لكنها تحتاج الوسائط فلا تعمل إلا قبل الاعتماد.
- **المجموعة المرجعية** — الأداة جاهزة والمقاطع لا. راجع
  [`eval/README.md`](../eval/README.md): هذا ما لا يستطيع أحد بناءه عنك.
- **التشكيل والملخص والعناوين** — خارج النطاق، وسهلة الإضافة بعد النصّ النهائي.
- **قياس المقاطع الصوتية في `npm run eval`** — النصّية تعمل، والصوتية تُتخطّى
  بوضوح حتى يُوصَل مُشغّل الخط الكامل بالأداة.
