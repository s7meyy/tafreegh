# التشغيل للتطوير

## المتطلبات

- Node.js ‏22 فأحدث
- Docker (لقاعدة البيانات والطوابير)
- `ffmpeg` — مطلوب ابتداءً من م1، غير مطلوب في م0

## الإقلاع

```bash
npm install
cp .env.example .env      # ثم املأ مفاتيح المزوّدين
docker compose up -d      # Postgres + Redis
npm run db:push           # إنشاء الجداول
npm run dev               # http://localhost:3000
```

## المفاتيح المجانية

| المزوّد | الرابط | الدور |
|---|---|---|
| Groq | <https://console.groq.com/keys> | التفريغ الأساسي (`whisper-large-v3`) |
| Gemini | <https://aistudio.google.com/apikey> | التفريغ الثاني + المراجعتان |

كلاهما بطبقة مجانية بلا بطاقة. راجع حدود الحصص وتحذير الخصوصية في
[`PLAN.md` § 3](PLAN.md#3-اختيار-النماذج--مجانية-بالكامل) قبل رفع مادة حساسة.

بدون المفاتيح يعمل م0 كاملًا (المجلدات والرفع)؛ مراحل التفريغ تحتاجها.

## الأوامر

| الأمر | الغرض |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run typecheck` | فحص الأنواع |
| `npm run db:generate` | توليد ملف ترحيل SQL بعد تعديل المخطط |
| `npm run db:push` | تطبيق المخطط مباشرة (للتطوير) |
| `npm run db:migrate` | تطبيق الترحيلات (للإنتاج) |
| `npm test` | الاختبارات |

## الحالة الحالية

**م0 مكتملة:** الهيكل، قاعدة البيانات، الواجهة العربية RTL، إنشاء المجلدات،
رفع الملفات، إضافة الروابط، لوحة المهام.

**التالي — م1 (التفريغ):** `ffmpeg` والتطبيع، التقطيع عند الصمت، مزوّدا Groq
وGemini خلف واجهة `TranscriptionProvider`، متتبّع الحصص، الدمج بالتداخل،
ومخطط الاختلاف بين المحرّكين.

## ما لم يُبنَ بعد ويجب ألا يُنسى

- **تسجيل الدخول** — `getCurrentUser()` تعيد مستخدمًا محليًا واحدًا. لا ترفع
  الموقع على إنترنت عام قبل م6.
- **الرفع المجزّأ المستأنف** — الحدّ الآن 200 ميغابايت لأن `formData()` تحمّل
  الملف في الذاكرة. يرتفع إلى 2GB في م5.
- **فحص الوسائط بالمحتوى** — الآن بالنوع والامتداد؛ `ffprobe` يتولّاه في م1.
