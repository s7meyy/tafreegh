# التشغيل للتطوير

## المتطلبات

- Node.js ‏22 فأحدث
- Docker (لقاعدة البيانات والطوابير)
- `ffmpeg` — مطلوب ابتداءً من م1، غير مطلوب في م0

## الإقلاع

```bash
npm install
cp .env.example .env      # ثم املأ مفاتيح المزوّدين
docker compose up -d      # Postgres + Redis
npm run db:push           # إنشاء الجداول
npm run dev               # http://localhost:3000
npm run worker            # في طرفية أخرى — بدونه لا يُفرَّغ شيء
```

**العامل عملية منفصلة عن خادم الويب.** مهمة التفريغ تستغرق دقائق، وطلب
HTTP لا ينتظرها. إن رفعت مقطعًا وبقي «في الانتظار»، فالعامل غير مشغَّل.

## المفاتيح المجانية

| المزوّد | الرابط | الدور |
|---|---|---|
| Groq | <https://console.groq.com/keys> | التفريغ الأساسي (`whisper-large-v3`) |
| Gemini | <https://aistudio.google.com/apikey> | التفريغ الثاني + المراجعتان |

كلاهما بطبقة مجانية بلا بطاقة. راجع حدود الحصص وتحذير الخصوصية في
[`PLAN.md` § 3](PLAN.md#3-اختيار-النماذج--مجانية-بالكامل) قبل رفع مادة حساسة.

بدون المفاتيح يعمل م0 كاملًا (المجلدات والرفع)؛ مراحل التفريغ تحتاجها.

## الحالة الحالية

**م0 مكتملة:** الهيكل، قاعدة البيانات، الواجهة العربية RTL، المجلدات،
الرفع، لوحة المهام.

**م1 مكتملة:** `ffmpeg` والتطبيع، التقطيع عند الصمت بتداخل، مزوّدا Groq
وGemini، متتبّع الحصص ولوحتها، الدمج بالتداخل، مخطط الاختلاف، والعامل.

**التالي — م2 (القياس):** مجموعة مرجعية بلهجات متعددة، وحساب WER،
و`npm run eval`. تأتي **قبل** المراجعتين عمدًا: بناء المراجعة بلا مقياس
بناءٌ في الظلام (§9 من الخطة).

## ما لم يُبنَ بعد ويجب ألا يُنسى

- **تسجيل الدخول** — `getCurrentUser()` تعيد مستخدمًا محليًا واحدًا. لا ترفع
  الموقع على إنترنت عام قبل م6.
- **الرفع المجزّأ المستأنف** — الحدّ الآن 200 ميغابايت لأن `formData()` تحمّل
  الملف في الذاكرة. يرتفع إلى 2GB في م5.
- **المحرّك المحلي** — `providersFor('local_only')` تعيد قائمة فارغة، فوضع
  «مشروع خاص» يفشل برسالة صريحة حتى يُضاف `faster-whisper` في م6.
- **جلب يوتيوب** — الصفوف تُنشأ بحالة `queued` لكن لا عامل لمرحلة `fetch` بعد.
- **حذف الوسائط بعد الاعتماد** — العمود والسجل موجودان، ومهمة `cleanup`
  لم تُبنَ (م4).
