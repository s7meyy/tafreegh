# تفريغ

منصّة تفريغ المقاطع الصوتية والمرئية العربية — فصحى وعاميات — بخط إنتاج من ثلاث مراحل: تفريغ آلي، ثم مراجعتان بنماذج لغوية، ثم اعتماد بشري وتصدير.

**الحالة:** م0–م5 مكتملة — الدورة كاملة تعمل: رفع ← تفريغ بمحرّكين ← مراجعتان ← اعتماد ← تصدير ← حذف الوسائط، مع دفعات كبيرة ورفع مستأنف حتى 2 غيغابايت. التالي: تسجيل الدخول والمسار المحلي (م6).

كل النماذج المستخدمة **مجانية**: Groq وGemini بطبقتيهما المجانيتين، مع مسار محلي بلا إنترنت للمشاريع الخاصة.

## ما الذي يفعله

- رفع ملف صوت أو فيديو حتى 2 غيغابايت، أو إدراج رابط يوتيوب — مقطع واحد أو دفعة.
  الرفع مجزّأ ومستأنف، فالانقطاع لا يُفقد ما وصل.
- تفريغ دقيق يراعي اللهجات (سعودية وخليجية ومصرية وشامية).
- مراجعتان متتاليتان لا تُصحّحان إلا ما لديهما دليل عليه.
- تنظيم في مجلدات/مشاريع، لكل مشروع مسرد مصطلحاته.
- محرّر اعتماد يعرض المراحل الثلاث جنبًا إلى جنب وكل تعديل بسببه.
- تصدير `txt` و `docx` و `md` و `srt`/`vtt`.
- حذف الوسائط بعد الاعتماد — لا يبقى إلا النص.

## التشغيل

```bash
npm install
cp .env.example .env
docker compose up -d
npm run db:push
npm run dev      # الواجهة
npm run worker   # في طرفية أخرى — المعالجة
```

التفاصيل في **[`docs/DEV.md`](docs/DEV.md)**.
