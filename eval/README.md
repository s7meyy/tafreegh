# المجموعة المرجعية

بلا قياس، كل تغيير في النماذج أو التعليمات قد يخفض الجودة ولا يلاحظه أحد.
هذه المجموعة هي المقياس، و`npm run eval` هو البوابة (§2.5 من الخطة).

## القاعدة

**كل مرحلة يجب أن تُنقص معدل الخطأ.** المرحلة التي ترفعه تُوقَف ولا تُدمج.
`npm run eval` يخرج برمز فشل حين تُخالَف هذه القاعدة، فيصلح للتشغيل الآلي.

## نوعا المقاطع

### مقطع نصّي — `kind: "text"`

يقيس **المراجعتين وحدهما**. يحتاج ملفين:

```
eval/fixtures/<الاسم>/
  meta.json        بيانات المقطع
  raw.txt          مخرَج التفريغ الآلي بأخطائه
  reference.txt    التفريغ الصحيح الذي كُتب يدويًا
```

لا يحتاج صوتًا ولا حصة تفريغ، فهو الأسرع لتطوير تعليمات المراجعة.

### مقطع كامل — `kind: "audio"`

يقيس **الخط كاملًا** من الصوت إلى النصّ المعتمد:

```
eval/fixtures/<الاسم>/
  meta.json
  reference.txt
eval/audio/<الاسم>.<الامتداد>      ← خارج git
```

مجلد `eval/audio/` مستثنى من git: ملفات الصوت ثقيلة، وقد تكون خاصة.
النصوص المرجعية وحدها هي التي تُحفظ في المستودع.

## `meta.json`

```json
{
  "kind": "audio",
  "dialect": "سعودي نجدي",
  "mode": "clean",
  "audio": "khutbah.m4a",
  "glossary": ["عبدالله بن سعود"],
  "note": "تسجيل هاتف، ضوضاء خلفية"
}
```

| الحقل | مطلوب | الوصف |
|---|---|---|
| `kind` | ✅ | `"text"` أو `"audio"` |
| `dialect` | ✅ | اللهجة — يُجمَّع التقرير بها |
| `mode` | — | نمط التفريغ، الافتراضي `clean` |
| `audio` | لـ `audio` | اسم الملف داخل `eval/audio/` |
| `glossary` | — | مصطلحات تُمرَّر للمحرّك وللمراجعة |
| `note` | — | ملاحظة تظهر في التقرير |

## التغطية المطلوبة

عشرة إلى خمسة عشر مقطعًا، ‏5–10 دقائق لكل واحد، تغطي:

- [ ] سعودي نجدي
- [ ] سعودي حجازي
- [ ] خليجي (إماراتي أو كويتي)
- [ ] مصري
- [ ] شامي
- [ ] فصحى واضحة
- [ ] تسجيل رديء الصوت
- [ ] متحدثان أو أكثر
- [ ] تنقّل بين العربية والإنجليزية

المقاطع الموجودة الآن اصطناعية، وضعناها ليعمل الأمر من اليوم الأول.
**استبدلها بمقاطعك أنت** — الرقم الذي يهمّك هو الرقم على لهجاتك وموضوعاتك،
لا على أمثلة عامة.

## التشغيل

```bash
npm run eval              # كل المقاطع
npm run eval -- --text    # النصّية وحدها (بلا صوت ولا حصة تفريغ)
npm run eval -- --name khutbah
```
